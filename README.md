# Cloud-Native AI Receptionist

A production-grade, automated, and scalable intelligent assistant platform. This project showcases the deployment of a microservices backend containerized with Docker, orchestrated via Kubernetes, provisioned using Infrastructure as Code (IaC), and continuously deployed using a robust CI/CD pipeline.

## Key Features & Engineering Highlights
* **Automated Infrastructure:** Full AWS infrastructure provisioning using **Terraform**, ensuring reproducible environment builds.
* **Orchestration & Scaling:** Container deployment on **AWS EKS (Kubernetes)** with pre-configured scaling and service routing.
* **Automated CI/CD:** End-to-end continuous integration and deployment pipeline engineered via **Jenkins**.
* **Microservices Architecture:** Fully containerized backend optimized for low-latency operations.
